# Project Statement

## 1. Problem Statement
-Managing books manually can make it difficult to keep track of books in a library. It can be challenging to know which books are available, issued, returned, or removed.
-The **Library Management System** provides a simple Python-based solution to manage basic library book operations in an organized way.

## 2. Scope of the Project
The project focuses on basic book management operations, including:
* Adding books to the library
* Displaying all books
* Searching for books
* Issuing books
* Returning books
* Deleting books
* Viewing library statistics
The project uses temporary data storage through Python lists. The data is cleared when the program is closed or restarted.

## 3. Target Users
The system is mainly intended for:
* Librarians
* Library staff
* Small libraries
* Students for academic and learning purposes

## 4. High-Level Features
1. **Add Books:** Add one or multiple books to the library.
2. **Display Books:** View all books in a formatted table.
3. **Search Books:** Search using Book ID, Book Name, or Author Name.
4. **Issue Books:** Change the status of an available book to issued.
5. **Return Books:** Change the status of an issued book back to available.
6. **Delete Books:** Remove books from the library collection.
7. **Library Statistics:** Display total, available, and issued book counts.
8. **Input Validation:** Handle invalid inputs for selected operations.
